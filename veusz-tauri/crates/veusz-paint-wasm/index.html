veusz-paint-wasm

Loads veusz_paint_wasm compiled to WebAssembly and renders a Veusz Scene JSON blob onto a <canvas> via WebGPU — no Python or Qt in the render path. This is the phase-4 strategic test from docs/parallel-paint-backends-plan.md.

Requires a browser with WebGPU enabled (Chromium 113+, Firefox Nightly with the flag, Safari Technology Preview).
