Veusz embed runtime

Live examples:

  • /example/ — fit.vsz with data baked into the .vsz
  • /url-example/ — ImportFileURL("data.csv"): the figure fetches its data from a URL at load (and re-fetches on change when poll_seconds>0)
  • /notebook/ — a browser-native MyST notebook: prose + a live JupyterLite (Pyodide) code cell + a live Veusz density figure, all client-side. Opens on a phone.
  • /theme-gallery.html — one complex figure in every shipped document theme (Publication, Dark, ggplot2, Seaborn, …).

Versioned runtime assets live under /embed/v<version>/.
