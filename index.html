Veusz figure runtime (WASM / Vello)

CORS-enabled hosting for the client-side Vello/WebGPU renderer used to embed Veusz figures in web pages. Pin a versioned path:

https://yipihey.github.io/veusz/figure-runtime/v0.1.0/veusz_paint_wasm_bg.wasm

Consumes the Scene IR from capture_document_scene / the render.scene RPC. See the GitHub repo for the <veusz-figure> component and exporter.
